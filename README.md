# My NeoVim Configuration

This is my NeoVim only configuration. To view my old VIM configuration
repository, go to https://github.com/synic/dotvim-legacy. It is now archived as
I do most of my editing in NeoVim exclusively.

To install, run the following:

```bash
$ git clone https://github.com/synic/dotvim ~/.config/nvim
```
